# AI 使用说明

实际投入时间：约 4 小时。

## 我的工作

我选择了“素材审核与发布排期 Agent”题目，并围绕考核要求确定项目方向：优先打通素材审核、时段查询、冲突处理和草稿保存链路，以 CLI 交付可运行、可验证的项目。

在架构与技术选型上，我参与比较原生实现和 Agent 框架，决定采用 AgentScope，并选择 OpenCode Go 的 DeepSeek 模型；结合业务场景，确定引入排期 Skill，让模型依据工具结果决定下一步。在方案讨论中，我确认了模型决策与业务代码的职责边界，以及单 Agent、SQLite 草稿存储等实现方向。

在关键业务节点上，我参与确定批量素材逐项处理、时段冲突时建议备选方案、待确认草稿占位、取消后释放时段、重复提交复用草稿等规则，并要求对输出状态和测试入口进行验证。

在效果验证和交付方面，我提出使用 DeepEval 评测，并要求检查企业使用中的业务缺口和作业要求。模型接口请求失败时，我提供了本机可正常运行的参考项目，帮助定位认证配置差异；我也参与检查 Trace 和文档，推动修正评测误判、补充验证记录并完善个人复盘。

## AI 辅助范围

我使用 Codex 协助分析需求、讨论架构和方案、编写与修改代码、接入 AgentScope 和 DeepEval、运行测试、排查问题及整理文档。项目代码和测试由 Codex 辅助生成与修改；我负责确定项目方向、参与架构及技术栈选型、确认关键业务规则，并根据验证结果提出反馈。

评估文档分别记录了离线 Mock 和真实模型的运行结果，以及评测器误判与修正过程。
