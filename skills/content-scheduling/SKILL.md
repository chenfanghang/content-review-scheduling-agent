# 素材审核与排期

1. 读取素材。素材不存在或缺少必要信息时，说明缺口并停止。
2. 检查审核规则。存在阻断风险时，说明原因并停止。
3. 查询用户要求的时段。可用时使用该时段；冲突时根据工具结果选择可用备选时段，或请求用户补充。
4. 对审核通过且时段可用的素材保存草稿。替代原定时间的草稿必须标记待确认；保存失败时如实报告失败。
5. 根据工具结果报告审核、时段、确认及草稿状态。草稿不是发布；未经用户同意不得将硬性要求的替代时间称为已确认。
